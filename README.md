## 🚀 How to Run

### Option 1: Double-click to Open
Simply double-click `index.html` to open it in your default browser.

### Option 2: Use a Local Server (Optional)
For the best experience, you can use a local server:

**Python 3:**
```bash
python -m http.server 8000
```

**Python 2:**
```bash
python -m SimpleHTTPServer 8000
```

**Node.js (if you have it):**
```bash
npx serve
```

**PHP:**
```bash
php -S localhost:8000
```

Then open http://localhost:8000 in your browser.

### Option 3: VS Code Live Server
If you use VS Code:
1. Install the "Live Server" extension
2. Right-click `index.html`
3. Select "Open with Live Server"

## 🛠️ Customization

### Change Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-600: #0284c7;  /* Blue */
    --gold-600: #ca8a04;     /* Gold */
    /* ... more colors */
}
```

### Modify Content
Edit text directly in `index.html` - no compilation needed!

### Add Images
Place images in the same folder and reference them:
```html
<img src="your-image.jpg" alt="Description">
```
